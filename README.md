# FastZero

It is a simple and well made to-do list api.

## Tools I use

- Python
- Poetry
- Taskipy
- Pytest
- Typos
- FastAPI
- Pydantic
- SQLAlchemy

## How to run

1. Clone:

```bash
git clone https://github.com/pedropaulodutra/fast_zero.git
```

2. Enter in the folder:

```bash
cd fast_zero
```

3. Install:

```bash
poetry install
```

4. Run:

```bash
poetry run task run
```

5. Read doc:
   Enter on http://localhost:8000/docs

## Tests

If you want to do tests, run:

```bash
task test
```

It will generate an `index.html` file in the `htmlcov` folder, open it on any browser.
